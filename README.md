# Credit Scoring Model Using Machine Learning
**Project Overview**
The Credit Scoring Model is a machine learning project developed using Python in Google Colab. The goal is to explore how machine learning classification algorithms can be used to assess creditworthiness based on customer data.
Credit scoring helps financial institutions evaluate the credit risk associated with applicants and supports more consistent, data-driven lending decisions.
This project implements and compares three classification algorithms: Logistic Regression, Decision Tree Classifier, and Random Forest Classifier.

**Objectives**
1. Understand the credit scoring problem using machine learning.
2. Load and explore the dataset.
3. Prepare the data for model training.
4. Build classification models using different algorithms.
5. Evaluate and compare model performance.
6. Understand how machine learning can support credit risk assessment.

**Technologies Used**
1. Programming Language: Python
2. Environment: Google Colab / Jupyter Notebook
3. Libraries: pandas, NumPy, scikit-learn, Matplotlib and Seaborn, where used in the notebook
4. Machine Learning: Supervised Learning, Classification

**Machine Learning Algorithms**
1. Logistic Regression
A classification algorithm used as a baseline model. It estimates the probability of a class and provides an interpretable approach to classification.
2. Decision Tree Classifier
A tree-based algorithm that learns decision rules from the input features to classify observations.
3. Random Forest Classifier
An ensemble learning algorithm that combines multiple decision trees to produce predictions and can capture complex relationships in data.

**Project Workflow**
1. Load the credit scoring dataset.
2. Explore and understand the data.
3. Perform the necessary data preprocessing.
4. Separate the features and target variable.
5. Split the data into training and testing sets.
6. Train the classification models.
7. Evaluate and compare the models using the metrics implemented in the notebook.
8. Review the results and identify the model that performs best on the evaluation data.

**Actual model results:**
Algorithm	Accuracy
1. Logistic Regression	66.80%
